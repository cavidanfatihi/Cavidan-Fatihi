# Ana səhifə platforma ikonları

Simple Icons saytının açıq SVG kolleksiyası sosial və musiqi platformalarının rəsmi nişanları üçün mənbə olaraq yoxlanıldı. jsDelivr üzərindən Spotify SVG faylının əlçatanlığı təsdiqləndi. Facebook, Instagram, Spotify və Apple Music SVG faylları daimi veb varlıqları kimi hazırlanıb; Deezer mənbə faylı həmin paket versiyasında tapılmadığı üçün ayrıca alternativ real SVG mənbə ilə tamamlanmalıdır.
